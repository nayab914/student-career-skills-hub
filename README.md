 🎓 Student Career & Skills Hub

Learn. Build. Grow.

Student Career & Skills Hub is a beginner-friendly website designed to help students explore technical skills, discover learning paths, and find suitable courses. It is built using HTML, CSS, and JavaScript.

 Features

- Explore popular technical skills.
- Follow a structured learning roadmap.
- Browse available courses in different fields.
- Select courses and calculate total fees.
- Plan study time based on weekly availability.
- Use the contact and interest form.
- Switch between dark and light modes.
- Filter courses and use interactive features.

Technologies Used

- HTML5
- CSS3
- JavaScript

 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open the website in your browser.
